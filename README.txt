HOW TO PUBLISH
Upload all files in this folder unchanged to any HTTPS static hosting service
(e.g. GitHub Pages, Netlify, Vercel, Cloudflare Pages).

IMPORTANT
A Progressive Web App requires HTTPS (or localhost) for the service worker and
offline installation features to work correctly.

INSTALL ON IPHONE
Open the published URL in Safari -> Share -> Add to Home Screen.

INSTALL ON ANDROID
Open the published URL in Chrome -> menu -> Add to Home screen / Install app.
